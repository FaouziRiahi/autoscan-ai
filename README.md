# AutoScan AI

AutoScan AI ist eine intelligente Lösung zur schnellen und einfachen Analyse von Fahrzeugen. Über einen OBD-II-Connector verbindet sich die App direkt mit dem Auto und liest relevante Fahrzeugdaten sowie vorhandene Fehlercodes aus.

## Lokal starten

```bash
npm install
npm run dev
```

## Enthaltene Funktionen

- Dashboard mit Kennzahlen, letzten Scans und offenen Aufgaben
- Durchsuch- und filterbarer Scan-Verlauf
- Detaillierte Fahrzeuganalyse mit Korrekturfunktion
- Geführter OBD-II-Scan mit Fortschrittsanzeige
- Mehrfach-Upload für Fahrzeugfotos und Dokumente
- PDF-Druckbericht und CSV-Export
- Responsive Oberfläche für Desktop, Tablet und Smartphone
- Live-Dashboard mit Drehzahl, Geschwindigkeit, Temperatur und Verbrauch
- Diagnosezentrum zum Lesen und Löschen von OBD-Fehlercodes
- Live-Monitor für einzelne PID-Sensorwerte
- Technisches OBD-Kommunikationsprotokoll
